
# 💬 Dynamic FAQ Page

A modern, responsive **FAQ (Frequently Asked Questions)** component built with **HTML, CSS, and Vanilla JavaScript** — perfect for corporate or SaaS websites.

## ✨ Features
- 🔹 Expand/Collapse All buttons  
- 🔹 Search filter for instant matching  
- 🔹 Smooth open/close animations  
- 🔹 Keyboard accessible (Enter/Space toggle)  
- 🔹 Responsive layout & animated gradient background  

## 🧠 Tech Stack
- HTML5  
- CSS3 (Flexbox, Transitions, Gradients)  
- Vanilla JavaScript
